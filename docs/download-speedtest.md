# 下载测速实现说明

## 两种模式

| 模式             | 并发      | 单节点时间 | 单节点数据 | 判定                        |
| ---------------- | --------- | ---------- | ---------- | --------------------------- |
| 快速检查（默认） | 最多 6 路 | 2 秒       | 3 MiB      | 在时限内接收满 3 MiB 才达标 |
| 详细测速         | 串行      | 5 秒       | 20 MiB     | 展示有效下载速度并支持排序  |

时间包含节点确认、连接、TLS 握手和下载。首次准备入口及任务结束后的清理另需时间。整批最多 180 秒或 200 MiB，先达到上限即停止；超过六个节点的快速检查按可用槽位继续调度。

快速检查保留每个节点的结果，不在第一条达标时提前结束。并行任务会共享带宽，因此未快速达标不等于线路不可用，也不等于不能播放视频。快速模式不按速度排名；详细模式至少接收 1 MiB 且下载持续 0.5 秒，才将结果纳入速度排名。

## 下载通道

运行配置生成器按需添加最多六组私有选择组和 HTTP listener：

- listener 只监听 `127.0.0.1`，每个使用独立端口和随机凭据。
- listener 的 `proxy` 字段绑定对应私有选择组，每个并发 worker 独占一个槽位。
- 私有配置只注入内核运行副本，不写回订阅原文或导出配置，不出现在日常节点列表中。
- 每次下载前确认节点属于该槽位的候选集合，切换后读回核验。
- 下载通过显式 HTTP CONNECT 和启用证书校验的 TLS 连接执行，不读取系统代理或环境代理，不在失败时回退直连。
- 不跨节点复用连接，不自动换源、跟随重定向或进行应用层下载重试。

代理组会递归展开、去重并检测循环。DIRECT、REJECT 等非代理出口不测试；存在歧义的同名节点会拒绝测试。链式节点保留内核原有链路语义，测试对象是整条链路。

## 测速源与计量

默认使用 Cloudflare 的 HTTPS 下载测速端点。快速模式请求 3 MiB，详细模式请求 20 MiB；同一批固定一个地址。自定义源应使用公共 HTTPS 域名、443 端口，不含凭据或 URL 片段，并返回足够大小的未压缩二进制或纯文本内容。

HTTP 错误、HTML/JSON 页面、压缩响应和异常中断不会作为有效结果。详细模式在遇到不适用的源响应时停止本批；快速模式保留该节点失败信息，并继续收集其他节点结果。

详细速度按响应体字节数除以接收响应头之后的下载时间计算，单位为 MiB/s。快速判定使用包含建连在内的总耗时，不将并行观测速度当作单独使用节点时的带宽上限。

批次派发前预留每个 worker 的数据预算，进度按全部任务已接收字节求和。预算不等于订阅账单的绝对上限：接收块、在途数据、协议开销及重传会带来额外流量。

## 取消与失效

取消会中止所有 worker 的下载或控制请求，不再派发后续节点。下载器销毁自有连接后，将所属选择组复位为 REJECT，只清理该入站的内核连接，并等待连续空快照确认异步清理完成。清理无法确认时停止后续测试，不清理其他应用的连接。

配置重载、配置 patch、主动订阅更新、内核停止或退出会取消任务并使结果失效。每个节点测试前及快捷选点前还会核对节点身份和组成员指纹，避免后台 provider 刷新后误用旧结果。

关闭测速面板不等于取消。任务状态保存在主进程，重新打开面板可以恢复查看；退出应用后不保留测速结果。

## 快捷选点

- 快速模式优先保留已经达标的当前节点，否则选择达标候选，不宣称该节点是最快。
- 详细模式选择当前批次有效结果中最快的节点。
- 只有用户点击后才改变发起测试的目标组，不更改分流规则或全局模式。
- 自动组不会被强制改为手动组；需要连带修改其他子组的情况会提示限制。
- 切换影响新连接，不强制关闭日常已有连接。

## 自动化验证

```sh
pnpm run format:check && pnpm run lint:check && pnpm run typecheck
pnpm test
pnpm exec electron-vite build
```

下载器与配置测试需要允许监听本机端口。实际 Mihomo 集成测试默认跳过，可用独立测试内核启用：

```sh
MIHOMO_TEST_BINARY=/absolute/path/to/mihomo pnpm exec vitest run src/main/speedtest/mihomo.integration.test.ts
```

集成测试在临时目录启动独立内核、本地模拟代理和 HTTPS 服务，不读取个人订阅、不启用 TUN、不修改系统代理。覆盖单节点与 provider 节点选点、六路入口隔离、坏节点不直连回退、模式切换及连接清理。

`src/main/speedtest/fixtures/` 中的 localhost 证书与私钥仅用于本地测试，不是真实服务凭据。不要将个人订阅链接、节点密码、真实配置或未脱敏截图添加到测试样例、文档或 Issue。

## 人工验收清单

自动化测试和源码构建不能替代完整客户端验收：

1. 验证订阅导入、日常节点切换与代理连接不受影响。
2. 使用自己有权测试的节点，核对下载连接链与实际出口。
3. 普通组选择 B、测速指定 A，确认日常选择保持 B，测速经过 A。
4. 待测节点失效而目标源仍可访问时，确认测试失败而不直连回退。
5. 检查六路并发、全部取消、预算耗尽、订阅更新与内核重启。
6. 分别验收 TUN、不同内核、不同 macOS 架构及最终安装包。
7. 确认快速检查结果没有被描述为视频平台可访问或持续播放不卡的保证。

本说明不包含个人订阅信息或真实节点的测速记录。
